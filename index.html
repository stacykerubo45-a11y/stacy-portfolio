CASE STUDY

Cargo SMS Management System

A private client project built to make customer communication easier for a cargo and logistics company.

The challenge

The company needed a more organised way to communicate shipment updates and other information to customers. Managing contacts and sending messages manually could become time-consuming, especially when communicating with many customers at once.

The solution

I built a web-based platform that allows staff to manage contacts, create reusable message templates, send bulk SMS, schedule messages and review messaging activity from one dashboard.

My role

I worked across the frontend and backend, including the user interface, API integration, database structure, authentication, contact management and messaging workflows.

Technologies

  • React
  • Node.js
  • Express
  • MongoDB
  • REST API

Key features

  • Contact management
  • Excel contact import
  • Bulk SMS messaging
  • Message scheduling
  • Reusable message templates
  • Delivery history and reports
  • User authentication
  • Automated messaging
  • Dashboard and reporting
